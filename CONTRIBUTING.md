# Contributing / Contribuer

Thanks for helping improve ArchViz Prompt Library!

## Add or improve a prompt

1. Open an issue describing the improvement or use case.
2. Propose a change via GitHub pull request.
3. Keep prompt text in English and explanations in French or English.
4. Use descriptive filenames and follow existing categories: `masters/`, `modules/`, `locks/`, `presets/`.
5. Explain the intended scene, model/version and known limitations when available.
6. Avoid conflicting instructions between modules and locks.

## Safety and rights

- Do not commit API keys, passwords, client information or confidential renderings.
- Only contribute text or examples you have the right to publish.
- Do not promise exact geometric or pixel fidelity from generative models.
- By submitting a contribution, you agree it may be distributed under the repository's CC BY 4.0 license.

## Suggestions

An issue can propose new modules for interiors, mountains, urban spaces, landscaping, materials, or camera matching.
