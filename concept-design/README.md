# Concept Design / Architectural Ideation

Experimental prompts for architectural **concept research**, not final project documentation.

Unlike photorealistic refinement, these prompts may intentionally change the design. Use the relevant level of creative freedom and retain any required site constraints. Proposals must be checked for feasibility, dimensions, structure, accessibility and regulations by qualified professionals.

## Workflow
1. Start with a brief, reference images or a simple Cinema 4D massing model.
2. Pick a concept prompt and set freedom with `design-freedom/`.
3. Generate distinct alternatives; label them A/B/C.
4. Critically assess spatial qualities and construction plausibility.
5. Rebuild a chosen idea in 3D before presenting it as a design proposal.

**Important:** Do not combine the strict photorealism master ('no redesign') with unconstrained concept exploration. Choose one mode.
