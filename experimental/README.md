Ces textes restent optionnels et ne remplacent pas les prompts maîtres.

- `subtle-warmth.md` : chaleur légère ; testé avec les deux blocs suivants dans T04, pas isolément.
- `distance-haze.md` : brume de profondeur ; ne doit pas préserver un défaut atmosphérique de la source par inadvertance.
- `texture-freedom.md` : enrichissement des matières ; peut entrer en tension avec une conservation exacte des motifs et joints.
- `material-id-guidance.md` : source en image 1, Material ID pass en image 2 ; T03 a été jugé moins riche visuellement. L’ID pass n’est pas un contrôle structurel garanti.
- `foreground-midground-fidelity.md` : priorité aux plans et objets importants ; T08 jugé trop factice, sans gain d’alignement démontré.

Un même prompt peut produire des variantes. Ne pas attribuer un changement à un bloc sur une seule génération. Les ajouts de T04 ont été testés ensemble : leurs effets individuels restent inconnus.
