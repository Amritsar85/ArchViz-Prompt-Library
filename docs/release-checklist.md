# Public release checklist

- [ ] Verify prompt files and presets are readable and have no contradictory instructions.
- [ ] Confirm license and attribution preference (CC BY 4.0).
- [ ] Remove API keys, billing data and identifiers.
- [ ] Confirm permission to publish every image, design and example.
- [ ] Add a reproducible test report using `tests/TEST_TEMPLATE.md`.
- [ ] Review README usage examples and English/French terminology.
- [ ] Create public GitHub repository and publish an initial release.
- [ ] Prefer a separate private workspace for professional/client tests.
